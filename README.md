# Altus WordPress Theme

A custom hand-coded WordPress theme — no page builder, no bloat. Built for speed and clean markup, with bespoke templates for the homepage and key landing pages.

## Features

- Hand-coded `front-page.php`, `header.php`, `footer.php` and template parts
- Custom `functions.php`: theme setup, menus, widget areas, performance tweaks
- Responsive CSS with a consistent spacing/typography scale
- Template-parts architecture for reusable sections

## Tech stack

- PHP (WordPress theme API)
- Vanilla CSS/JS

## Install

1. Upload the theme folder to `wp-content/themes/`
2. Activate under Appearance → Themes
